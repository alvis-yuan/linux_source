## 🎯 核心发现

### 架构特点

1. **清晰的分层架构**
   ```
   应用层 → 适配层 → 会话层 → Link层 → 传输层 → 物理层
   ```

2. **状态机驱动设计**
   - Link层：8个状态，23个事件
   - 认证模块：9个状态
   - 识别模块：5个状态

3. **异步非阻塞**
   - CP操作异步化（认证不阻塞主循环）
   - 回调通知机制
   - 支持线程和轮询两种模式

4. **可靠传输机制**
   - 滑动窗口协议
   - 自动重传（超时重传、快速重传）
   - 序列号管理（SEQ/ACK）
   - 累积确认

5. **统一编解码**
   - ControlCodec提供统一接口
   - 自动处理大小端转换
   - 支持多种参数类型

### 关键流程

#### 连接建立流程（5个阶段）
```
物理连接 → Link协商 → 认证 → 识别 → 会话就绪
```

#### 认证流程（6步）
```
1. Device请求证书
2. Accessory读取证书（CP）
3. Accessory发送证书
4. Device请求签名挑战
5. Accessory签名挑战（CP）
6. Accessory发送签名响应
7. Device确认认证结果
```

#### 识别流程（3步）
```
1. Device启动识别
2. Accessory发送配件信息
3. Device确认识别结果
```

- 快速路径（常见情况优化）

- 完善的重传机制
